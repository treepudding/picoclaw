# PicoClaw 本地运行指南

个人 fork 用，不再拉取 upstream master，在此基础上自己迭代做个人 Agent。本文档记录如何编译、启动、停止，方便以后查阅。

---

## 一、编译（改代码后必做）

```bash
cd /Volumes/ORICO/workspace/github/picoclaw
go build -o ~/.local/bin/picoclaw ./cmd/picoclaw
```

若需走代理（例如下载 toolchain）：

```bash
export http_proxy=http://127.0.0.1:7890
export https_proxy=http://127.0.0.1:7890
go build -o ~/.local/bin/picoclaw ./cmd/picoclaw
```

---

## 二、启动

### 方式 A：前台运行（调试用）

```bash
picoclaw gateway
```

Ctrl+C 即停止。

### 方式 B：后台运行

```bash
nohup picoclaw gateway > ~/.picoclaw/gateway.log 2>&1 &
```

### 方式 C：launchd 服务（开机自启）

```bash
# 首次安装：复制 plist
cp /Volumes/ORICO/workspace/github/picoclaw/com.picoclaw.gateway.plist ~/Library/LaunchAgents/

# 启动
launchctl load ~/Library/LaunchAgents/com.picoclaw.gateway.plist
```

---

## 三、停止

### 若为前台或 nohup 启动

```bash
pkill -f "picoclaw gateway"
```

或先查 PID 再杀：

```bash
ps aux | grep picoclaw
kill -9 <PID>
```

注意：`ps` 里会看到 Cursor 的 extension-host 进程名字里带 picoclaw，不要误杀。只杀路径是 `~/.local/bin/picoclaw gateway` 的那条。

### 若为 launchd 启动

```bash
launchctl unload ~/Library/LaunchAgents/com.picoclaw.gateway.plist
```

或只停不卸：

```bash
launchctl stop com.picoclaw.gateway
```

---

## 四、重启（改配置或改代码后）

1. 先停止（见上一节，按你实际用的启动方式选）。
2. 若改了代码：先编译（见「一、编译」），再启动。
3. 再按「二、启动」用同一方式启动。

---

## 五、常用路径

| 用途     | 路径 |
|----------|------|
| 配置     | `~/.picoclaw/config.json` |
| 日志     | `~/.picoclaw/gateway.log` |
| 工作区   | `~/.picoclaw/workspace`（可在 config 里改） |
| 会话存储 | `~/.picoclaw/workspace/sessions/` |
| 二进制   | `~/.local/bin/picoclaw`（编译输出目录） |
